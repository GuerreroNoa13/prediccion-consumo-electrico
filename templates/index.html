Proyecto de Álgebra Lineal

Predicción del consumo mensual de electricidad

Este programa estima cuántos kWh consume un hogar en un mes usando una regresión lineal múltiple. Los coeficientes se calculan con matrices, resolviendo la ecuación normal con NumPy.

El modelo

consumo = β₀ + β₁·personas + β₂·dispositivos + β₃·horas A/C + β₄·temperatura

β = (XᵀX)⁻¹ XᵀY

Cómo usarlo

Sigue los pasos del panel izquierdo en orden. El led de cada paso se enciende cuando ya se puede usar: primero se cargan los datos, luego se entrena el modelo y después se pueden ver los coeficientes, predecir y evaluar.
